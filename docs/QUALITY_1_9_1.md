# Проверка CAS 1.9.1

13 ноября 2026 года. Основа — стабильный v1.9.0 (`13bbe9e`), с последующим
отчётом о публикации `54eb84f`. Исправления и мобильный пульт версии 1.9.0 сохранены.

## Изменения

- Реализация renderer разделена на 12 контроллеров с собственным состоянием,
  конфигурацию, модели уровня и очередей, а также совместимый фасад приложения.
  Точка входа renderer.js содержит 96 строк. Схемы пользовательских данных,
  preload, CSP, зависимости и целевые платформы не изменены.
- Сопоставление синтаксических деревьев подтвердило эквивалентность 180
  перенесённых методов, 74 начальных значений и двух независимых моделей
  после учёта перенаправления через фасад.
- Порядок браузерных скриптов и состав app.asar обновлены для новых модулей.

## Локальная проверка

- Windows x64, Node 22.23.2, Electron 43.8.4. Чистая npm ci без обновления
  зависимостей; lockfile изменён только в полях версии приложения.
- npm test: 155/155. Новые проверки охватывают загрузку скриптов без Node API,
  изоляцию состояния экземпляров и совместимость обратных вызовов фасада.
- prepare:online и check:online прошли с проверенным кэшем того же манифеста.
- build-win прошёл с закреплённым Electron 43.8.4 через electronDist. Проверены
  36 файлов app.asar и запуск включённых yt-dlp, Deno и FFmpeg.
- Полный smoke из исходников прошёл: восстановление двух дек, мобильный пульт,
  ленивые пэды, настройка вкладок, перенос звучащего трека, повтор с обрезкой,
  пересчёт анализа, Unicode-пути, перезапуск без автостарта и сохранение при закрытии.
  Повторный таймаут запуска исследован через CDP: данные восстановлены, шрифты
  загружены, ошибок нет, но скрытая страница не получает кадры. Ожидание двух
  кадров после подготовки ограничено 250 мс; тест моделирует полное отсутствие
  кадров. Подготовка данных и шрифтов по-прежнему ожидается полностью.
  После исправления сценарий из исходников завершился успешно.
- YAML workflow разобран через js-yaml: Windows/macOS/Linux собираются нативно,
  macOS universal, Linux x64 AppImage/deb и Windows x64 NSIS; публикация сначала draft.
- После исправления загрузки полный smoke готового Windows-приложения прошёл.
  build:win создал NSIS-установщик; Get-AuthenticodeSignature: NotSigned.
  git diff --check прошёл. Служебные файлы и локальные профили не включены в исходники.

## Ограничения

Физические телефоны, прослушивание на концертном оборудовании и ручной GUI
macOS/Linux не проверялись. Нативные CI-результаты и публикация фиксируются
после фактического завершения проверок.
