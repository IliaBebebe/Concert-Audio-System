# Проверка профессионального интерфейса CAS

Ветка: `codex/pro-mac-interface`. Версия приложения остаётся 1.4.0; отдельный релиз этих изменений не публиковался.

## Изменения

- Графитовые панели, компактная верхняя панель инструментов, единая типографика Manrope, спокойные акценты дек A/B и строка состояния снизу.
- В левой панели оставлен только логотип CAS, без повторяющих его названия и подписи. В ней и на стартовом экране используется готовая прозрачная версия из проекта (`assets/cas-logo-transparent.png`), без перерисовки. Исходные файлы сохранены.
- Поиск музыки и справка по клавишам доступны из верхней панели, включая восстановление соответствующего вынесенного и свёрнутого блока.
- Сохранены фейдеры и измерители dBFS из предыдущей задачи. Аудиодвижок в этой задаче не изменён.
- Стиль выделен в `console.css`; локальные шрифты и лицензия включены в упаковку всех платформ.

## Фактическая проверка на Windows

- `npm test`: 66/66. `node --check renderer.js`, `git diff --check` успешны.
- Изолированный профиль Electron 43.8.4 с локальными тестовыми WAV: загрузка обеих дек, воспроизведение, Space для паузы, Escape для остановки, запуск и остановка пэда, mute, таймер, окно параметров трека.
- Нативный ArrowUp на фейдере: 70 → 71%, значение аудиодвижка 0.71. Tab в верхней панели переводит фокус с поиска на справку. Кнопка поиска раскрывает панель и фокусирует поле; справка обновляет aria-expanded и получает фокус.
- Вынос и возврат микшера; кнопки верхней панели восстанавливают свёрнутые окна дек и справки. Во время основных проверок ошибок renderer и необработанных Promise не зарегистрировано.
- При viewport 1384×861 и 1000×660 горизонтального переполнения страницы нет. На компактном размере логотип, микшер и транспорт видимы, второстепенные блоки доступны прокруткой; подписи кнопок пэдов помещаются.
- Стартовое окно 600×440: логотип и обе кнопки видимы, содержимое помещается без прокрутки.
- `npm run build-win` успешно. Содержимое `console.css`, renderer, обоих TTF, лицензии и логотипа в app.asar совпадает с исходниками.
- Упакованный Windows EXE запущен с отдельным профилем: обе деки загружаются, поиск и справка работают, логотип и оба начертания Manrope загружены, ошибок загрузки ресурсов нет.

Скриншоты сняты в работающем Electron: [основное окно](screenshots/pro-interface-windows.png), [стартовый экран](screenshots/pro-welcome-windows.png). В деках используются тестовые сигналы, не музыкальный каталог пользователя.

Интерактивная проверка macOS/Linux и нового стабильного релиза не выполнялась. Цели упаковки Windows x64, universal macOS и Linux x64 сохранены.

После замены логотипа повторно проверены 1384×861 и 1000×660: изображение загружается, отдельные подписи отсутствуют, горизонтального переполнения нет. Прозрачный PNG включён в app.asar без изменения содержимого; упакованное стартовое окно 600×440 показывает его без чёрного фона и прокрутки. Повторная Windows-сборка и 66 тестов успешны. Скриншоты обновлены.
