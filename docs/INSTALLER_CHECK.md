# Оформление установщика CAS

Windows использует штатный NSIS-мастер electron-builder: приветствие, лицензия,
выбор пользователя, каталог установки, прогресс и завершение. Оформление задано
в `build/installer.nsh`; установка, обнаружение предыдущей версии, повышение прав,
ярлыки и удаление остаются в шаблонах electron-builder.

Новые тексты доступны на русском и английском. Для других языков новые тексты
показываются на английском, стандартные страницы сохраняют встроенные переводы.
Версия берётся из `${VERSION}` во время сборки. В изображениях версии нет.

Исходник оформления изображений — `scripts/generate-installer-art.py`.
Для регенерации нужен Pillow: `python scripts/generate-installer-art.py`.
Два готовых BMP хранятся в Git; Python и Pillow не нужны для обычной сборки.
Изображения RGB, 24 бита, в двойном разрешении для масштабирования NSIS.

## Проверка на Windows, 31 октября 2026

- `npm run build-win` выполнен успешно перед сборкой установщика.
- NSIS-установщик собран из проверенного `release/win-unpacked` командой
  `npm exec electron-builder -- --win nsis --x64 --prepackaged release/win-unpacked --publish never`.
  Компиляция включает установщик и деинсталлятор.
- В настоящем EXE проверены русское приветствие, лицензия, выбор пользователя,
  каталог установки и отмена. Существующая установка CAS не заменялась.
- Прогресс и русское завершение проверены отдельным NSIS-предпросмотром с теми же
  макросами оформления и пустой секцией вместо записи файлов и реестра.
  Реальная установка, обновление, удаление и запуск с финального флажка не выполнялись.
- `npm test`: 75/75; проверки упакованного интерфейса и online-инструментов успешны.
- Повторная генерация обоих BMP даёт идентичные SHA-256; `git diff --check` успешен.
- YAML релизного workflow разобран; цели Windows x64, universal macOS, Linux x64
  AppImage и deb и их имена сохранены. У последнего проверенного CI-запуска
  `41182265053` все три платформенные сборки успешны, но это предыдущая версия
  исходников. С текущим оформлением macOS/Linux CI не запускался.

Локальный результат: `release/Concert-Audio-System-Setup.exe`. Новый релиз не публиковался.
