CAS 1.7.1 исправляет отображение поиска и точек старта треков. Рекомендуем обновиться пользователям CAS 1.7.0.

### Что исправлено

- **Обновлённый внешний вид.** Значки поиска снова находятся внутри полей обеих дек. Метка старта видна рядом с названием трека, в том числе в узкой деке и при длинном названии.
- **Параметры повторяющихся треков.** Изменение названия, номера и точки старта обновляет все вхождения файла в обеих деках. Сброс ручного номера возвращает нумерацию по очереди.
- **Хранение данных.** В README добавлено описание настроек, ручных данных треков и резервного копирования.
