# Проверка CAS 1.7.0

Локальные проверки выполнены 8 ноября 2026 года на Windows x64, Node.js 22.23.2.
Выпуск подготовлен из изменений интерфейса и мобильного пульта в `cbe3202`.

## Автоматические проверки

- Чистая установка зависимостей через `npm ci`; версии зависимостей не обновлялись.
- `npm test`: 119/119. Дополнительно проверены ограничение попыток PIN, запрет
  запросов с чужих веб-сайтов, смена данных доступа при перезапуске сервера,
  некорректные URL и команды, граница файлового доступа и восстановление
  перенесённых очередей с повторяющимися треками и пустой исходной декой.
- `npm run prepare:online` и `npm run check:online`: успешно. После сетевого
  отказа начальной загрузки использован существующий проверенный Windows-кэш
  с тем же манифестом закреплённых версий; yt-dlp, Deno и FFmpeg запускаются.
- `npm run build-win`, `node scripts/check-packaged-online.js`,
  `node scripts/check-packaged-ui.js` и `npm run build:win`: успешно.
  Проверено совпадение 20 файлов внутри app.asar, включая мобильный клиент,
  сервер, генератор QR и Lucide. Версия архива — 1.7.0.
- Локальный NSIS: 181999879 байт. `Get-AuthenticodeSignature`: `NotSigned`.
- YAML release workflow разобран через js-yaml. Проверены три нативных runner,
  зависимость публикации от всех сборок и создание только черновика.
- QR-код с полным 128-битным токеном считан OpenCV; получен исходный URL.
- `git diff --check` и синтаксические проверки изменённых JavaScript: успешно.

## Проверка интерфейса и воспроизведения

Проверки выполнены в отдельном экземпляре Windows-приложения с искусственными
WAV-файлами и изолированным профилем. Установленная CAS и библиотека пользователя
не изменялись.

- Загрузка папки, воспроизведение WAV, клавиатурный перенос трека между деками
  без остановки текущего звука, запуск пэда с клавиатуры.
- Переход на следующий трек внутри плейлиста при свёрнутом окне: фоновый таймер
  активен, музыка продолжается; окно восстанавливается.
- Меню открывается стрелкой вниз с клавиатуры. При размере 1000×700 нет
  горизонтального переполнения; присутствуют все 12 пэдов.
- При первом запуске обрезка тишины, стабилизация и нормализация выключены.
  Настройки обработки, громкость и назначение пэда восстанавливаются.
- После переноса сохранённый состав и порядок обеих очередей точно совпадают
  после перезагрузки окна упакованного приложения; музыка автоматически не стартует.
- Мобильный пульт подключается по PIN из отдельного браузера, получает состояние
  через SSE и управляет воспроизведением, паузой, запуском и остановкой пэдов.
  На экране 390×844 нет горизонтального переполнения. В состояниях Play и Pause
  виден только соответствующий значок.
- Во время основных сценариев не зарегистрированы ошибки JavaScript.

## Ограничения проверки

Мобильный пульт проверен в браузере Windows с мобильным размером экрана;
физические iPhone/Android и их Wi-Fi не проверялись. Считывание QR проверено
программно. Проверка состояния аудиоплееров и Web Audio не заменяет прослушивание
на концертном оборудовании. Ручная проверка GUI и звука macOS/Linux не выполнялась.
Сборки остаются без подписи издателя и нотариализации.
