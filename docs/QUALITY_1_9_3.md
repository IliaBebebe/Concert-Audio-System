# Проверка CAS 1.9.3

15 ноября 2026 года. Основа — CAS 1.9.2, коммит `ad67233`.

## Проверяемое поведение

- Первый запуск воспроизведения с пустым кэшем анализа ожидает определения начала звука. Остановка, пауза и смена проигрывателя отменяют отложенный запуск. Проверяются ручная точка старта, кэш и отказ декодирования.
- Яндекс Музыка: вход через код устройства, ожидание и отмена подтверждения; OAuth передаётся только API, без передачи токена медиа-хостам и аргументам внешних процессов.
- YouTube и SoundCloud: импорт Netscape cookies только выбранного сервиса, проверка срока действия и наличия данных входа, временный файл для загрузчика с удалением после завершения или ошибки. Проверяются шифрованное хранение, отключение и защита IPC от посторонних окон.
- Форматы превью SoundCloud исключены до загрузки; выбранный формат и длительность дополнительно проверяются перед сохранением. Старое короткое превью проходит повторную подготовку, включая запуск из сохранённой библиотеки. При отказе оригинал сохраняется.

## Подтверждено до подготовки релиза

- Windows x64: 184/184 автоматических теста прошли. Сборка 1.9.2 с исправлениями прошла проверку нативных инструментов и сравнение 40 упакованных файлов с исходниками.
- Нативный smoke исходников и распакованного Windows-приложения прошёл с изолированным профилем: запуск, обе деки, воспроизведение, мобильный пульт, пэды, переходы, обрезанные повторы, первый старт с холодным анализом без ручной точки, Unicode-пути, восстановление без автостарта и сохранение при закрытии.
- Реальное Electron safeStorage на Windows: шифрованный цикл записи/чтения и отключение аккаунта прошли с тестовыми данными.
- Интерфейс проверен через agent-browser при 1400×900 и 1000×700; новая кнопка доступна с клавиатуры.
- «Carly Rae Jepsen — Call Me Maybe»: поиск во всех трёх источниках выполнен. YouTube запросил подтверждение входа; Яндекс без авторизации не предоставил полную запись; официальный результат SoundCloud предоставил только 30-секундные форматы preview. Публичный endpoint Яндекса успешно выдал код устройства; подтверждение личного аккаунта не выполнялось.

## Ограничения

Полная загрузка после входа с личными аккаунтами не подтверждена. Успешные тесты транспорта авторизации не гарантируют доступность конкретного трека. Ручной GUI macOS/Linux и прослушивание на концертном оборудовании не проверялись.

## Локальная проверка версии 1.9.3

- `npm test`: 186/186. Версии package.json, lockfile и окна «О программе» согласованы. Release YAML разобран; проверены три нативных runner, создание только draft после успеха всех платформ и четыре прежних имени пакетов.
- `prepare:online` и `check:online` прошли: yt-dlp 2026.10.26, Deno 2.9.8 и FFmpeg 6.1.1. `build-win`, проверки инструментов и сравнение 40 упакованных файлов прошли.
- Нативный smoke исходников и итоговой Windows-сборки прошёл, включая новое окно подключения, получение безопасных статусов без передачи секретов в renderer, закрытие по Esc и первый старт без тишины. Окно визуально проверено при 1400×900 и 1000×700, фокус после закрытия возвращается к кнопке «Аккаунты».
- Добавлено пользовательское руководство `docs/ONLINE_MUSIC.md`; в окне аккаунтов есть короткие шаги и прямые действия. Проверены копирование только кода устройства, отмена, запрет произвольных URL справки и отсутствие промежуточного меню при прямом подключении сервиса.
- `build:win` создал установщик 1.9.3: 182019877 байт, Get-AuthenticodeSignature — NotSigned, SHA-256 `cebafde49da427e6ee75fa071222167211c68eb6887beab2083cbb2d0bc7cd1a`. Проверки содержимого и нативный smoke после сборки NSIS также прошли. Первая попытка build-win встретила временную блокировку каталога EBUSY; после проверки отсутствия запущенного CAS повторная сборка завершилась успешно.
