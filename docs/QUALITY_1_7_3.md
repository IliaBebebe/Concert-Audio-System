# Проверка CAS 1.7.3

Проверка выполнена 11 ноября 2026 года. Основа — опубликованный CAS 1.7.2
и последующая документация релизной ветки, коммит `cace2bc`.

## Найденные ошибки и исправления

- Повторный клик «Настройки» снова открывал закрытую панель из-за двух
  обработчиков. Переход к поиску или справке из настроек оставлял нужный блок
  скрытым. Обработчик остался в контроллере вкладок; переход раскрывает владельца блока.
- Выпадающие списки перехватывались глобальными клавишами воспроизведения.
  Теперь их клавиатурное управление не меняет трек, громкость или mute.
- Импорт файлов вызывал отсутствующий `renderDeckTracks`; новая очередь не
  сохранялась правильно. Исправлены отображение и восстановление точного состава
  очереди, включая повторы и файлы вне основной библиотеки. Main разрешает только
  конкретные аудиофайлы, выбранные системным диалогом; соседние файлы и папки
  остаются недоступными. Пути выбранных файлов сохраняются в config.json.
- После переноса играющего трека и паузы обработчик `onplay` возвращал старую
  деку. Теперь он использует текущее местоположение плеера. Пауза во время
  асинхронного возобновления также учитывается, не теряясь до события `onplay`.
- Повтор игнорировал точку старта и обрезку конца, а графическое обновление
  останавливалось у обрезанного конца. Проверены обрезанный конец и обычная
  граница HTML5 loop; при асинхронном повторном запуске Howler не создаётся
  дополнительное воспроизведение.
- Изменение порога и защитного запаса очищало только Map, оставляя старые границы
  в треках и кэше осциллограмм. Анализ пересчитывается; устаревшие задачи отбрасываются.
- Поздний ответ сохранённой онлайн-библиотеки перекрывал новый поиск. Ответы и
  состояние занятости теперь учитывают поколение запроса.
- Пульт пересоздавал кнопки на каждом обновлении состояния и терял фокус.
  Кнопки пэдов сохраняются, список треков доступен с клавиатуры и сохраняет фокус.
  Неверный PIN отображает ошибку, введённый текст сохраняется, ошибочный SSE закрывается.
- Нулевое время при повторном запуске портило работающий таймер. Неверное значение
  больше не заменяет текущий отсчёт.
- Меню «Воспроизведение / Пауза» не возобновляло паузу; исправлено условие.
  Объявленные Ctrl/Cmd+O, Ctrl/Cmd+Q, Ctrl/Cmd+, и F5 получили обработчики.
  F5 обновляет список без перезагрузки приложения. Неверные подсказки Shift+A/B
  убраны из импорта: эти клавиши продолжают выбирать целевую деку.
  Из README удалена отсутствующая функция блокировки клавишей L.

## Автоматические проверки

- Windows x64, Node.js 22.23.2, Electron 43.8.4; зависимости из package-lock.json
  через `npm ci`, без обновления версий библиотек.
- `npm test`: 138/138. Добавлены проверки воспроизведённых ошибок, точного доступа
  к выбранным файлам и запрета соседних файлов, восстановления повторов,
  отмены устаревших ответов, таймера и клавиш меню.
- `node scripts/smoke-packaged.js --source`: фактический Electron с отдельным
  профилем, обе деки, Unicode/#/% в путях, старт с 3,5 с, пэд, пауза через меню,
  перенос играющего трека, повтор с обрезкой и обычный HTML5 loop, пересчёт
  защитного запаса, повторный запуск и сохранение при немедленном закрытии.
- Workflow разобран js-yaml: windows-latest, macos-latest, ubuntu-latest;
  Windows x64 NSIS, universal macOS DMG, Linux x64 AppImage и deb; draft только
  после завершения всех сборок. Расширенный smoke включён для всех платформ.
- `prepare:online` и `check:online` прошли с проверенным Windows-кэшем того же
  закреплённого манифеста: yt-dlp 2026.10.26, Deno 2.9.8, FFmpeg 6.1.1.
  Первичная загрузка средствами Node на этой машине завершилась `fetch failed`;
  использован существующий локальный кэш, без отключения TLS-проверок.
- `npm audit --omit=dev`: 0 уязвимостей. Полный npm ci сообщил о 6 moderate
  предупреждениях в зависимостях разработки; попутное обновление сборщика не выполнялось.
- Финальные `build-win`, проверки packaged-online и packaged-ui, расширенный
  smoke готового Windows-приложения и `build:win` прошли. Упакованы и сверены
  20 файлов интерфейса. Для локальной сборки использован установленный Electron
  43.8.4 через `--config.electronDist=node_modules/electron/dist`.
  `Get-AuthenticodeSignature` Windows-установщика — `NotSigned`.
- Синтаксис изменённых JavaScript, версии package/lockfile и `git diff --check`
  проверены. Генерируемые ресурсы npm не включены в исходный коммит.

## Проверка интерфейса и сети на Windows

Использованы искусственные WAV и отдельный профиль. Установленная CAS и музыка
пользователя не изменялись. Управление — через agent-browser и CDP настоящего Electron.

- Проверены все семь выносных блоков: отделение, сворачивание, разворачивание и
  возврат; перенос блока во вкладку, удаление вкладки с возвратом на Основную.
- Обе деки, поиск и пустая выдача, очистка поиска, пауза и перенос, настройки,
  справка, завершение и сброс таймера. В наблюдаемых сценариях нет ошибок JavaScript.
- 1400×900 и 1000×700: визуальная проверка, горизонтального переполнения нет.
- Пульт в изолированном браузере при 390×844: соединение с реальным сервером CAS,
  выбор трека клавишей Enter, сохранение фокуса пэда и трека при обновлениях,
  неверный PIN с сообщением и сохранением ввода; переполнения и ошибок страницы нет.
- Живой поиск YouTube вернул 8 записей. Тестовая запись Blender
  `aqz-KE-bpKQ` подготовлена, сохранена, добавлена в очередь и запущена как
  локальный m4a; Howler сообщил playing=true и длительность 634,7 с.

## Ограничения

Проверка не доказывает отсутствие всех возможных ошибок. Прослушивание на
концертном оборудовании, физические телефоны и ручные GUI/аудио macOS/Linux
не проверялись. Сведения о финальных пакетах и нативном CI добавляются после сборок.
